# 皮草货物管理与记账管理系统 — 实施计划

> **For agentic workers:** 本文档是系统的总体实施计划，按严格顺序推进。每个阶段的产出文档是下一阶段的输入，不可跳跃执行。

**目标:** 从零开始构建一个皮草行业后台库存管理与记账系统，覆盖商品管理、多级库存、销售记账、工资奖金结算、数据可视化与导出。

**架构:** React（前端）+ Go（后端）+ PostgreSQL（数据库），前后端分离，RESTful API。

### 任务 1.2：核心业务流程梳理

需画出以下 8 条业务流程的流程图：

1. **采购入库流程（进货入库房）**
   - 从货源地进货 → 选择已有商品 → 填写入库数量、进货价 → 库房库存增加 → 记录入库日志
   - **说明：入库是将货物放入库房，而非分配给门店。商品必须先到商品管理中创建。**

2. **快捷补货流程（库存总览处）**
   - 在库存总览中选择已有商品 → 点击快捷入库 → 填写补货数量和进货价 → 库房库存增加 → 记录入库日志

3. **上架流程（库房 → 门店）**
   - 选择目标门店 → 选择库房中的商品 → 填写上架数量 → 校验库房库存充足 → 库房库存减少、门店库存增加 → 记录上架日志

4. **下架流程（门店 → 库房）**
   - 选择来源门店 → 选择商品 → 填写下架数量 → 校验门店库存充足 → 门店库存减少、库房库存增加 → 记录下架日志

5. **调拨流程（门店 → 门店）**
   - 选择来源门店 → 选择目标门店 → 选择商品 → 填写调拨数量 → 校验来源门店库存充足 → 来源门店库存减少、目标门店库存增加 → 记录调拨日志

6. **商品售出流程**
   - 选择售出门店 → 按分类筛选商品 → 选择有库存的商品 → 填写售价、售出人员 → 门店库存减少 → 生成出售记录

7. **出售退货流程**
   - 选择出售记录 → 填写退货数量 → 门店库存恢复 → 出售记录标记退货 → 记录退货日志→ 关联的提成回退（若已结算则需重新结算）

8. **工资奖金结算流程**
   - 选择时间范围 → 选择目标销售员 → 查看未结算出售记录（排除已退货） → 系统按方案规则计算提成 → 手动确认生成结算单 → 结算单状态变更

### 任务 1.4：工资奖金方案详细规则

#### 类型一：固定提成

- **通用规则**：每售出一件，提成固定金额 X 元（适用于所有未在方案中单独配置的商品）
- **单品例外**：在**工资奖金方案中**可对指定商品单独设置提成金额，优先级高于通用规则。此配置不作用于商品基础信息，仅在该方案关联的用户计算提成时生效。
- **计算示例**：
  - 通用规则：每件提成 5 元
  - 单品 A 在方案中配置：每件提成 10 元
  - 单品 B 在方案中配置：每件提成 20 元
  - 张三（绑定此方案）本月售出：A 商品 3 件 + B 商品 2 件 + C 商品（未单独配置）8 件
  - 提成计算 = 3×10 + 2×20 + 8×5 = 30 + 40 + 40 = 110 元

#### 类型二：件数阶梯

支持两种计算模式：

**模式 A：累计重算（回溯）**

达到更高档位后，之前所有的件数都按较高档位重新计算。

示例：
- 档位：1-10 件 → 每件 5 元，11-20 件 → 每件 8 元，21 件以上 → 每件 12 元
- 张三本月售出 22 件
- 计算：22 件全部按 12 元计算 = 22 × 12 = 264 元

**模式 B：阶梯计算（累进、不回溯）**

每一段的件数独立计算，不回溯，各段结果相加。

示例：
- 档位：1-10 件 → 每件 5 元，11-20 件 → 每件 8 元，21 件以上 → 每件 12 元
- 张三本月售出 22 件
- 计算：
  - 第 1-10 件：10 × 5 = 50 元
  - 第 11-20 件：10 × 8 = 80 元
  - 第 21-22 件：2 × 12 = 24 元
  - 总计 = 50 + 80 + 24 = 154 元

2. **商品分类页** — 左侧分类树（支持多级、拖拽排序） + 右侧分类详情/编辑表单 + 新增分类按钮

3. **商品列表页** — 顶部搜索栏（名称/SKU/分类筛选） + 商品表格（含图片缩略图）+ 新增按钮（弹出多SKU表单）+ 编辑/删除操作

4. **货源地管理页** — 搜索栏 + 货源地表格 + 新增/编辑/删除按钮

5. **库存总览页** — 三栏卡片（库房库存总数 / 在途门店库存 / 合计库存） + 各门店库存表格（可展开看商品明细） + 快捷补货按钮（选择已有商品快速入库）

6. **入库页** — 入库表单：选择货源地 → 选择商品（已有或快速新增） → 填写数量、进货价、批次号 → 确认入库；下方入库记录列表

7. **上架页** — 上架表单：选择目标门店 → 从库房库存中选择商品 → 填写上架数量 → 确认上架；下方上架记录列表

8. **下架页** — 下架表单：选择来源门店 → 从门店库存中选择商品 → 填写下架数量 → 确认下架；下方下架记录列表

9. **调拨页** — 调拨表单：选择来源门店 → 选择目标门店 → 选择商品（来源门店库存中） → 填写调拨数量 → 确认调拨；下方调拨记录列表

10. **库存流水页** — 筛选栏（按类型/时间/商品/门店） + 流水表格（类型标签含入库/上架/调拨/售出/下架/退货/盘点调整，来源、目标、商品、数量、操作人、时间）

11. **商场门店页** — 上部：商场表格（高亮选中行） + 新增/编辑/删除；下部：选中商场下的门店表格 + 新增/编辑/删除。联动选择。

12. **出售记账页** — 出售表单：选择售出门店 → 按分类树筛选 → 商品列表（仅显示有库存的，标注库存数量） → 选择商品后填写售价、售出人员 → 确认出售

13. **出售退货页** — 退货表单：选择出售记录（按门店/销售员/时间筛选） → 填写退货数量 → 确认退货；下方展示退货记录

14. **出售记录页** — 筛选栏（时间范围/门店/销售员/商品） + 出售记录表格（商品、门店、销售员、售价、数量、时间、退货状态、结算状态） + 快捷导出按钮

13. **方案管理页** — 方案列表表格 + 新增按钮 → 弹出方案编辑弹窗：方案名称、月薪、方案类型（固定提成/件数阶梯）、计算模式（仅件数阶梯时可选）、通用规则金额、单品例外列表（选择商品+金额的增删）、阶梯档位列表（仅件数阶梯时）

15. **用户列表页** — 搜索栏 + 用户表格（姓名、登录账号、角色、关联门店列表、绑定方案名称） + 新增/编辑弹窗（含角色选择下拉、多选门店、工资方案选择下拉（可为空）、登录账号+密码设置）

16. **角色管理页** — 角色表格（名称、描述、用户数） + 新增/编辑弹窗

17. **奖金结算页** — 筛选栏（时间范围、销售员选择下拉） → 点击查询 → 显示未结算出售记录列表（含系统自动计算的预计提成，排除已退货） + 已结算Tab → 选中记录后点击"生成结算单" → 确认弹窗 → 生成结算单

18. **我的工资奖金页** — 时间筛选（默认本月） + 月工资摘要卡片 + 提成明细列表（关联出售记录，标注结算状态和退货状态） + 已结算汇总卡片

19. **下载中心页** — 导出类型列表（商品/库存/出售记录/流水/结算单/全量备份） + 导出按钮（选择格式）+ 导入恢复按钮（上传文件）

按模块列出所有需要的 API 端点（HTTP Method + Path + 简要说明）：

**商品模块：**
- `GET    /api/v1/categories` — 分类列表
- `POST   /api/v1/categories` — 新增分类
- `PUT    /api/v1/categories/:id` — 编辑分类
- `DELETE /api/v1/categories/:id` — 删除分类
- `GET    /api/v1/products` — 商品列表（支持分类、关键词筛选）
- `POST   /api/v1/products` — 新增商品
- `PUT    /api/v1/products/:id` — 编辑商品
- `DELETE /api/v1/products/:id` — 删除商品

**货源地模块：**
- `GET    /api/v1/suppliers` — 货源地列表
- `POST   /api/v1/suppliers` — 新增货源地
- `PUT    /api/v1/suppliers/:id` — 编辑货源地
- `DELETE /api/v1/suppliers/:id` — 删除货源地

**库存模块：**
- `GET    /api/v1/inventory/overview` — 库存总览（库房库存 + 各门店库存 + 合计，直接加总）
- `GET    /api/v1/inventory/warehouse` — 库房库存列表
- `POST   /api/v1/inventory/inbound` — 入库（进货入库房）
- `GET    /api/v1/inventory/inbound` — 入库记录列表
- `POST   /api/v1/inventory/shelve` — 上架（库房 → 门店）
- `GET    /api/v1/inventory/shelve` — 上架记录列表
- `POST   /api/v1/inventory/unshelve` — 下架（门店 → 库房）
- `GET    /api/v1/inventory/unshelve` — 下架记录列表
- `POST   /api/v1/inventory/transfer` — 调拨（门店 → 门店）
- `GET    /api/v1/inventory/transfers` — 调拨记录列表
- `GET    /api/v1/inventory/logs` — 库存流水（入库/上架/调拨/售出/下架/退货/盘点调整）
- `GET    /api/v1/inventory/stores/:storeId` — 门店库存详情

**商场门店模块：**
- `GET    /api/v1/malls` — 商场列表
- `POST   /api/v1/malls` — 新增商场
- `PUT    /api/v1/malls/:id` — 编辑商场
- `DELETE /api/v1/malls/:id` — 删除商场
- `GET    /api/v1/malls/:mallId/stores` — 某商场下的门店
- `POST   /api/v1/stores` — 新增门店
- `PUT    /api/v1/stores/:id` — 编辑门店
- `DELETE /api/v1/stores/:id` — 删除门店

**销售模块：**
- `POST   /api/v1/sales` — 商品售出
- `GET    /api/v1/sales` — 出售记录列表（支持时间、门店、销售员、商品筛选）
- `GET    /api/v1/sales/:id` — 出售记录详情
- `PUT    /api/v1/sales/:id` — 编辑出售记录（未结算的可编辑）
- `POST   /api/v1/sales/:id/return` — 出售退货（退货数量、恢复门店库存、标记退货）
- `GET    /api/v1/sales/returns` — 退货记录列表

**角色模块：**
- `GET    /api/v1/roles` — 角色列表
- `POST   /api/v1/roles` — 新增角色
- `PUT    /api/v1/roles/:id` — 编辑角色
- `DELETE /api/v1/roles/:id` — 删除角色

**用户模块：**
- `GET    /api/v1/users` — 用户列表（含角色名称、关联门店列表、绑定方案名称）
- `POST   /api/v1/users` — 新增用户（含角色+关联门店+密码+方案绑定（可为空））
- `PUT    /api/v1/users/:id` — 编辑用户（可修改角色、关联门店、方案绑定）
- `DELETE /api/v1/users/:id` — 删除用户
- `GET    /api/v1/users/:id/schemes` — 查询用户绑定的工资方案

**工资奖金方案模块：**
- `GET    /api/v1/schemes` — 方案列表
- `POST   /api/v1/schemes` — 新增方案（含通用规则、单品例外列表、阶梯配置）
- `PUT    /api/v1/schemes/:id` — 编辑方案
- `DELETE /api/v1/schemes/:id` — 删除方案
- `GET    /api/v1/schemes/:id` — 方案详情（含规则明细和阶梯配置）

**奖金结算模块：**
- `GET    /api/v1/settlements` — 结算单列表
- `POST   /api/v1/settlements/preview` — 预览结算（传入时间范围+销售员ID → 返回未结算记录+每笔预计提成+合计）
- `POST   /api/v1/settlements` — 生成结算单
- `GET    /api/v1/settlements/:id` — 结算单详情（含明细列表）

**我的工资奖金模块（个人视角）：**
- `GET    /api/v1/my-salary` — 我的工资奖金（传入时间范围 → 月薪 + 提成明细 + 已结算/未结算汇总）

**仪表盘模块：**
- `GET    /api/v1/dashboard/overview` — 概览数据
- `GET    /api/v1/dashboard/store-ranking` — 门店排行
- `GET    /api/v1/dashboard/category-ratio` — 品类占比
- `GET    /api/v1/dashboard/sales-trend` — 销售趋势
- `GET    /api/v1/dashboard/seller-ranking` — 销售员排行
- `GET    /api/v1/dashboard/stock-alert` — 库存预警（含库房和门店）
- `GET    /api/v1/dashboard/slow-moving` — 滞销分析

**数据导出模块：**
- `GET    /api/v1/export/products` — 导出商品
- `GET    /api/v1/export/inventory` — 导出库存（库房+门店）
- `GET    /api/v1/export/sales` — 导出售出记录
- `GET    /api/v1/export/logs` — 导出库存流水
- `GET    /api/v1/export/settlements` — 导出结算单
- `GET    /api/v1/export/backup` — 全量备份导出
- `POST   /api/v1/import/restore` — 备份恢复导入

**认证模块：**
- `POST   /api/v1/auth/login` — 登录（返回 JWT Token）
- `POST   /api/v1/auth/refresh` — 刷新 Token
- `GET    /api/v1/auth/me` — 获取当前登录用户信息
